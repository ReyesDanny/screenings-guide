# Explaining Screenings and Exams to Parents

An interactive staff reference for Centro de la Familia Head Start / Early Head Start Family Services and health staff. It covers anemia, dental, growth, hearing, vision, immunizations, lead, physical exam, nutrition, TB, and developmental screening, with English/Spanish parent scripts and printable parent handouts.

**Live site:** https://reyesdanny.github.io/screenings-guide/

The page is a single self-contained file (`index.html`) with no external scripts or fonts. To update it, replace `index.html` and commit; GitHub Pages republishes within a few minutes.

For staff guidance only; it does not replace advice from a child's health care or dental provider.
